# Project Definition — 288 - IFRS 18

This folder holds the filled-in Demand Charter (project definition) for
demand **288 - IFRS 18**, in three equivalent formats plus a preview image:

- `288-IFRS18-Demand-Charter.md` — Markdown version (readable/diffable in git).
- `288-IFRS18-Demand-Charter.pptx` — PowerPoint slide matching the original
  Demand Charter template layout.
- `288-IFRS18-Demand-Charter.docx` — Word document version, for the
  knowledge base.
- `288-IFRS18-Demand-Charter-preview.png` — rendered preview of the slide,
  for quick review without opening PowerPoint.

All three documents contain the same content. The `.pptx` and `.docx` files
are generated from scripts in [`../demand-charter/`](../demand-charter/)
(`generate_charter_pptx.py` and `generate_charter_docx.py`); re-run those
scripts and copy the output here if the content needs to be regenerated
after edits.
